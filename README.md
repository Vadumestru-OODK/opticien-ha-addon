# Home Assistant-add-on: Opticien Sync

Sync-server voor de klantkaarten-app van Opticien op de Koffie.

Toevoegen in Home Assistant: Instellingen > Add-ons > Add-on-winkel > ⋮ > Repositories,
en plak de link van deze repository.

Het token vul je in op het tabblad Configuratie van de add-on. Het staat niet in deze code.
De gegevens staan in /share/opticien en blijven bij een update gewoon staan.
